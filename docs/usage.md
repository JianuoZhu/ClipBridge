# 使用教程

本教程面向使用已经部署好的 ClipBridge 的人。部署者先完成 [公网服务器与家中节点部署](deployment.md)，本机体验则按 [README](../README.md#快速开始) 启动。

## 1. 打开站点并登录

1. 从部署者取得站点网址、用户名和密码，例如 `https://clip.example.com`。
2. 在电脑或手机浏览器打开该网址。
3. 输入部署时配置的用户名和密码，点击“登录”。页面没有“注册”入口。
4. 在自己的其他设备重复以上步骤，使用同一组凭据。

普通设备只需要浏览器，不需要安装 Node.js、Docker 或 WireGuard。默认会话保持 30 天；清除 Cookie、会话过期或部署者修改凭据后，需要重新登录。

当前是一个共享空间：任何使用这个账号登录的设备，都能读取和删除其中的所有内容。不是每台设备或每个人各有一份独立空间，具体机制见 [登录说明](authentication.md)。

## 2. 从电脑把文字发到手机

1. 在电脑页面的输入框粘贴文字。
2. 点击“发送”，或按 `Ctrl + Enter`（macOS 为 `Cmd + Enter`）。
3. 手机保持同一站点页面打开，内容会自动出现在“最近”列表里。
4. 点击该条内容的“复制”，再到目标应用粘贴。

反过来从手机发送、电脑复制也是相同流程。只在系统里按“复制”不会自动发送到 ClipBridge；网页需要你明确粘贴和发送。

如果浏览器不允许复制，按页面提示检查剪贴板权限，或者手动选择文字复制。长文字在列表中只显示预览，点击“复制”会复制完整内容。单条文字默认最多 1 MiB，按 UTF-8 字节数计算，中文和 Emoji 往往占多个字节。

## 3. 从一个设备把文件发到另一个设备

1. 在“传文件”区域点击“选择”，可一次选择多个文件；电脑也可以把文件拖入该区域。
2. 等待上传完成。上传进度到达 100% 表示浏览器已发送完数据，仍需等文件出现在“最近”列表中，才算服务器保存成功。
3. 在另一台设备打开该文件对应的“下载”。文件会交给浏览器保存，手机可能显示下载列表或保存位置选择器。

每批选择的文件依次上传。默认单文件上限为 512 MiB，所有有效文件与活跃上传共用 5 GiB 配额；部署者可以调整。空文件会被拒绝。

上传中断后需要重新选择文件上传。下载接口支持 Range，但能否在中断后继续下载取决于浏览器或下载工具；页面没有单独的“续传”按钮。下载链接也要求有效登录会话，不能作为匿名公开分享链接使用。

## 4. 删除与自动过期

- 点击某条内容旁的“删除”，确认后该内容从共享空间移除，其他在线设备也会更新。
- 删除文件不会删除设备上已经下载的副本，删除文字也不会撤回已复制到其他应用的内容。
- 默认内容保留 24 小时，从发送成功时开始计时，到期后不能再通过服务访问。
- 到期的磁盘文件在下一次清理时移除，周期为 15 分钟；删除和过期不提供回收站或恢复按钮。
- “最近”最多显示 100 条未过期内容。更旧的内容仍可能占配额，直到到期或被删除。

需要长期保存的内容，请及时下载或复制到自己的存储位置。

## 5. 退出、重连与移动端

点击页面右上角“退出”会撤销当前浏览器会话并清空页面。共享该 Cookie 的其他页面也会退出；其他浏览器和设备的独立会话不受影响。关闭标签页本身不会退出账号。

页面连接中断时会显示离线状态，并尝试重新连接；切回页面或恢复网络后，会重新检查登录状态和内容列表。家中节点必须保持开机和联网，手机离线时不能发送或获取新内容。

可以把网址加入书签；浏览器若提供“添加到主屏幕”或安装入口，也可使用。应用外壳缓存不包含私人文字、API 响应或下载文件，不提供离线同步能力。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 不知道账号或忘记密码 | 联系部署者；部署者在家中节点修改 `.env` 并重启，页面没有密码找回功能 |
| 提示“登录状态未保存” | 使用部署者提供的完整 HTTPS 地址，检查 Cookie 是否被浏览器阻止 |
| 提示尝试次数过多 | 等待限速窗口后重试；代理部署中其他设备的失败尝试也可能影响当前设备 |
| 发出后另一设备没看到 | 检查是否访问同一站点、登录同一共享账号，恢复网络或重新打开页面 |
| “文件超过大小限制”或“文字内容过大” | 减小内容，或请部署者调整对应上限 |
| “存储空间配额不足” | 删除不再需要的文件，等待旧文件过期，或请部署者调整容量 |
| 无法连接家中节点 | 请部署者检查家中电脑、应用容器与 WireGuard，见 [部署排错](deployment.md#验证与排错) |

不要把账号分享给需要隔离数据的其他人。关于数据保存和加密范围，请阅读 [安全模型](../SECURITY.md)。
